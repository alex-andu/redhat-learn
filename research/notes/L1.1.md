## Afirmații-cheie
- Shell = interpretor; pe RHEL implicit bash. Buclă: prompt → citire → alias → expandări → căutare (funcție, builtin, PATH) → execuție → `$?`.
- `$?` = exit status al ultimei comenzi; 0 = succes; 127 = command not found; 126 = găsită, neexecutabilă (bash(1), EXIT STATUS).
- Quoting: apostrofuri literale; ghilimele duble permit `$`, `` ` ``, `\`; backslash un caracter.
- Prompt implicit RHEL (`[\u@\h \W]\$ `) — afirmat din /etc/bashrc RHEL/Fedora; `\W` = ultimul element al căii.
- Alias: fără spații în jurul lui `=`; persistență prin `~/.bashrc`.
