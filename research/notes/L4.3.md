# Research — L4.3 Întreruperea procesului de boot

**Obiectiv oficial:** C4-3 „Interrupt the boot process in order to gain access to a system”.
**Stare cercetare:** parțială. docs.redhat.com (RHEL 10) → HTTP 403, necitit; procedura (rd.break, remount /sysroot, chroot, passwd, /.autorelabel) provine din cunoștințe despre ghidurile RHEL 8/9 și din dracut.cmdline(7); NU a fost recitită din ghidul RHEL 10. Citit efectiv (2026-11-16): freedesktop.org `systemd.special` (rescue/emergency target).

## Afirmații-cheie
- La meniul GRUB2, tasta `e` editează temporar intrarea selectată; `Ctrl+x` pornește; `Esc` anulează (grub manual).
- `rd.break` (dracut.cmdline(7)): oprește boot-ul în initramfs, înainte de `switch_root`; shell root fără parolă. Rădăcina reală este montată la `/sysroot`, doar pentru citire.
- Procedură: `mount -o remount,rw /sysroot` → `chroot /sysroot` → `passwd root` → `touch /.autorelabel` → `exit` → `exit`.
- `/.autorelabel`: la boot, SELinux (dacă este activ) reetichetează sistemul de fișiere; `passwd` rulat în initramfs creează /etc/shadow cu context greșit.
- `systemd.unit=rescue.target` / `emergency.target` cer parola root (sulogin), deci nu ajută când parola e pierdută.
- Un GRUB protejat cu parolă împiedică editarea fără parolă GRUB; parolă de firmware/disc criptat — în afara lecției.
- Reetichetarea poate dura minute; sistemul repornește singur la final.

## Comenzi
`mount -o remount,rw /sysroot`, `chroot /sysroot`, `passwd root`, `touch /.autorelabel`, `exit`, `cat /proc/cmdline`, `getenforce` (doar menționat; C10).

## Nesigurante
- Numele liniei din GRUB (`linux`, `linuxefi`) pe RHEL 10; lecția spune „linia kernelului”.
- Dacă RHEL 10 mai cere `load_policy`/alternative; lecția folosește doar `/.autorelabel`.
- Textul exact al promptului din initramfs (`switch_root:/#`) — ilustrativ.
- Această procedură NU se aplică pe sisteme care nu sunt ale tale; lecția are avertisment.
