# Research — L2.5 Instalarea și ștergerea pachetelor Flatpak

**Obiectiv oficial:** C2-4 „Install and remove Flatpak software packages”.
**Stare cercetare:** parțială. docs.redhat.com (RHEL 10) → HTTP 403; necitit. Citit parțial docs.flatpak.org (doar `flatpak info`: opțiunile `-u/--user`, `--system`, `--installation`, `--show-origin` etc.). Restul: man pages flatpak-install(1), flatpak-uninstall(1), flatpak-list(1), flatpak-run(1), flatpak-update(1), flatpak-search(1), flatpak-info(1).

## Afirmații-cheie
- `flatpak install [REMOTE] REF` (REF = ID aplicație, ex. reverse-DNS), opțiuni `--user`/`--system`, `-y/--assumeyes`, `--noninteractive`.
- `flatpak uninstall REF`, `--unused` (șterge runtime-uri nefolosite), `--delete-data` (șterge datele aplicației).
- `flatpak list [--app] [--runtime]`, `flatpak info REF` (cu `--show-origin`), `flatpak run REF`, `flatpak update`.
- Aplicațiile Flatpak sunt izolate (sandbox) și depind de „runtime”-uri instalate separat.

## Nesigurante
- Identificatorii reali ai aplicațiilor din remote-ul Red Hat (lecția folosește un ID fictiv).
- Prompturile exacte de confirmare și formatul tabelelor (Ilustrative).
- Comportamentul pe RHEL 10 față de RHEL 9 (neverificat).
