# Research — L2.3 Instalare și actualizare din CDN, repository remote sau sistem local

**Obiectiv oficial:** C7-5 „Install and update software packages from Red Hat Content Delivery Network, a remote repository, or from the local file system” (lecția este „casa” obiectivului; categoria C7 are alte lecții în capitolul ei).
**Stare cercetare:** parțială. docs.redhat.com (RHEL 10) → HTTP 403 (2026-11-16); necitit. Consultat: DNF Command Reference upstream (2026-11-16), man pages/cunoștințe: subscription-manager(8), dnf.conf(5).

## Surse
- DNF Command Reference: `upgrade` (`update` alias învechit; `upgrade NUME`), `check-update` (cod de ieșire 100 = există actualizări, 0 = niciuna, 1 = eroare), `install` cu cale/URL, `downgrade`, `history`, `--best`, `-y`, `--enablerepo/--repo`, `--nogpgcheck`, `makecache`, `clean`.
- subscription-manager(8): `register`, `status`, `list --available/--consumed`, `attach`, `repos --list`.
- dnf.conf(5): `installonly_limit`, `exclude`, `keepcache`.
- Index RHEL 10: „Register your RHEL system”, „Update RHEL content”, „Install RHEL content”.

## Afirmații-cheie
- Sistemul înregistrat primește repository-urile Red Hat (CDN) prin certificate de entitlement; fără înregistrare, repository-urile oficiale nu sunt accesibile.
- `dnf upgrade` actualizează toate pachetele; `dnf upgrade X` doar pachetul X; `dnf check-update` doar verifică.
- Kernelul este pachet „installonly”: actualizarea instalează o versiune nouă lângă cele vechi (limită `installonly_limit`; de confirmat valoarea implicită pe RHEL 10); activarea cere reboot.
- Instalare din sistem local: `dnf install ./f.rpm` sau ISO montat (L2.1).
- Instalare din remote: `dnf install URL` sau repository `baseurl=https://`.

## Comenzi și opțiuni
`subscription-manager register/status/unregister/repos/--list`, `dnf check-update`, `dnf upgrade [X]`, `dnf upgrade --security` (de confirmat disponibilitatea pe RHEL 10), `dnf updateinfo` (de confirmat), `dnf install ./f.rpm | URL`, `dnf downgrade`, `dnf history`, `dnf makecache`, `needs-restarting -r` (de confirmat pachetul/numele în RHEL 10).

## Nesigurante
- Comanda exactă de înregistrare recomandată în RHEL 10 (`subscription-manager register` vs `rhc connect`): lecția prezintă `subscription-manager`, cu notă de confirmare.
- Existența și sintaxa `--security`, `updateinfo`, `needs-restarting -r` în RHEL 10.
- Valoarea implicită `installonly_limit`.
- Nu se folosesc credențiale reale; exemplele folosesc valori fictive.
