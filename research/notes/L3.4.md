# Research — L3.4 Bucle: for

**Obiectiv oficial:** C3-2 „Use Looping constructs (for, etc.) to process file, command line input”.
**Stare cercetare:** parțială. Citit (2026-11-16): GNU Bash Manual „Looping Constructs” — `for name in words; do …; done`; listă goală ⇒ corpul nu rulează, status 0; `for name; do` ≡ `in "$@"`; `for ((e1; e2; e3))`; `while` (rulează cât statusul testului e 0), `until` (cât e nenul); statusul buclei = al ultimei comenzi din corp; `break`, `continue`. docs.redhat.com necitit.

## Afirmații-cheie
- Lista poate fi: cuvinte, glob (`*.txt`), expansiune cu acolade (`{1..5}`), `$(comandă)`, `"$@"`.
- `while read -r linie; do …; done < fișier` procesează un fișier rând cu rând (corect pentru spații în rânduri; `for x in $(cat f)` sparge pe spații — word splitting).
- `seq 1 5` generează secvențe; `{1..5}` este expansiune bash.
- `break`/`continue`.
- Glob fără potrivire rămâne literal (implicit) — se verifică `[ -e "$f" ]`.

## Comenzi
`for`, `while`, `until`, `read -r`, `seq`, `break`, `continue`, `cat`, `wc -l`, `basename`.

## Nesigurante
Output-uri reconstituite; comportamentul `nullglob`/`failglob` doar menționat în deep dive din bash(1) (`shopt`).
