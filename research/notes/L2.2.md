# Research — L2.2 Instalarea și ștergerea pachetelor RPM

**Obiectiv oficial:** C2-2 „Install and remove RPM software packages”.
**Stare cercetare:** parțială. docs.redhat.com (RHEL 10) → HTTP 403 la accesare (2026-11-16), necitit. Consultat: DNF Command Reference upstream (dnf.readthedocs.io, 2026-11-16) + man pages/cunoștințe (rpm(8), dnf(8)).

## Surse
- DNF Command Reference: `install` (nume, @grup, cale RPM locală, URL), `remove` (și `clean_requirements_on_remove`), `autoremove`, `search` (AND implicit, `--all`), `info`, `list`, `provides`, `repoquery`, `reinstall`, `history` (list/info/undo/redo/rollback), `-y`.
- rpm(8): `-q`, `-qa`, `-qi`, `-ql`, `-qc`, `-qd`, `-qf`, `-qp`, `-V`, `-K`, `-i`, `-v`, `-h`, `-e`, `--import`.
- Index RHEL 10: „Install RHEL content”, „Remove unnecessary RHEL content”, „DNF command reference” (titluri; conținut necitit).

## Afirmații-cheie (din referința upstream)
- `dnf install` acceptă nume, `@grup`, cale locală `.rpm` și URL; instalează dependențele.
- `dnf remove` șterge și pachetele care depind de țintă; cu `clean_requirements_on_remove` (implicit activ) șterge și dependențele devenite inutile.
- `dnf search` caută în nume și rezumat (substring, case-insensitive); `--all` include descrieri.
- `dnf provides` caută după fișier/capabilitate (acceptă și `*/nume`).
- `update` este alias învechit pentru `upgrade`.
- `dnf history` are ID-uri de tranzacții; subcomenzi `undo`, `redo`, `rollback`.
- `rpm -q` interoghează baza locală; `rpm -qp` interoghează un fișier `.rpm` neinstalat.

## Comenzi și opțiuni
`dnf install/remove/reinstall/autoremove/search/info/list [--installed|--available]/provides/history/group list|info|install|remove`, `-y`, `--assumeyes`; `rpm -qa/-qi/-ql/-qc/-qd/-qR/-qf/-qp/-V/-K/-ivh/-e`.

## Diferențe față de RHEL 8/9
De confirmat: dacă `dnf group` sintaxa (`dnf group install "Nume"`) este neschimbată în RHEL 10; dacă `dnf install` pe `.rpm` local verifică semnătura implicit (comportament depinde de `localpkg_gpgcheck`).
