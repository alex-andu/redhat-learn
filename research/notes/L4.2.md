# Research — L4.2 Targets systemd: boot manual și target implicit

**Obiective oficiale:** C4-2 „Boot systems into different targets manually”; C7-3 „Configure systems to boot into a specific target automatically”.
**Stare cercetare:** parțială. docs.redhat.com (RHEL 10) → HTTP 403, necitit. Citit efectiv (2026-11-16): freedesktop.org `systemd.special` (rescue/emergency/multi-user/graphical/default.target; `systemd.unit=` și alias `1` pentru rescue). Restul: `systemctl(1)`, `systemd.target(5)`, `systemd.special(7)`, `kernel-command-line(7)`, `bootup(7)`.

## Afirmații-cheie
- Target = unitate `.target` care grupează alte unități; reprezintă o „stare” a sistemului (fosta noțiune de runlevel).
- `graphical.target` pulls `multi-user.target`; `default.target` este un alias (symlink) către unul din ele; dacă lipsește, implicit compilat = `graphical.target`.
- `rescue.target`: sistem de bază, sisteme de fișiere montate, shell de rescue; `emergency.target`: cel mai minim, shell pe consolă, nu pornește servicii sau montări (rădăcina poate fi doar-citire).
- `systemctl get-default`, `systemctl set-default TARGET` (creează/actualizează `/etc/systemd/system/default.target`), `systemctl isolate TARGET` (schimbă imediat; oprește unitățile care nu sunt necesare), `systemctl list-units --type=target`, `systemctl list-unit-files --type=target`, `systemctl list-dependencies TARGET`.
- Boot într-un target doar o dată: parametrul kernelului `systemd.unit=TARGET.target` (kernel-command-line(7), systemd(1)) adăugat în meniul GRUB (`e`, apoi `Ctrl+x`); aliasul `1` pentru rescue (systemd.special).
- Mapare runlevel → target (systemd.special(7)): 0 poweroff, 1 rescue, 2/3/4 multi-user, 5 graphical, 6 reboot.
- `rescue.target`/`emergency.target` cer parola root (sulogin) — comportament documentat în sulogin(8).

## Comenzi
`systemctl get-default|set-default|isolate|list-units --type=target|list-unit-files --type=target|list-dependencies|rescue|emergency`, `ls -l /etc/systemd/system/default.target`.

## Nesigurante
- Linia din GRUB care se editează se numește `linux` (RHEL 9, UEFI/BIOS); pe RHEL 10 nu am confirmat; lecția spune „linia care începe cu `linux`”.
- Comportamentul exact al `systemctl isolate graphical.target` pe un server fără GUI instalat (target-ul poate exista, dar lipsesc pachetele grafice).
